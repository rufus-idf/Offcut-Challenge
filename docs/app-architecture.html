Offcut Challenge

B2B material offcuts marketplace for UK workshops — Architecture & Flow Reference

Next.js 15 TypeScript Supabase Stripe Vercel Soft launch: 5–10 workshops

💰 Business Model

£29/mo
Flat Subscription
Marketplace access + private stock tracking. Purchased on the external marketplace website. Stripe Checkout → webhook → invite email → app access. Verified UK businesses only.
5%
Transaction Fee
Taken automatically on each sale between workshops via Stripe Connect — handled inside the app. 95% goes to the seller, 5% to the platform.
+
Camera App (Add-on)
Separate purchasable product on the marketplace website — Python desktop app (Windows EXE). Billed separately via Stripe. Requires £29/mo subscription to push stock into Supabase.

🌐 Marketplace Website — Product Storefront (Separate Site)

A separate public-facing website that describes and sells all products — including the Offcut Challenge app and the Camera App. Customers purchase here first, before they ever touch the Offcut Challenge app itself.

What it shows

  • Product descriptions & pricing
  • Offcut Challenge — £29/month subscription
  • Camera App — separate purchase
  • Other products (future)
  • FAQs, case studies, contact

What happens on purchase

  • Stripe Checkout on marketplace site
  • Webhook fires on successful payment
  • Buyer receives email with access link
  • Link takes them to Offcut Challenge signup
  • Subscription status pre-confirmed in DB

Relationship to the app

  • Separate domain / codebase
  • Shares the same Stripe account
  • Webhook writes into Offcut Challenge Supabase DB
  • No login required to browse or buy
  • App login is separate from marketplace site

Do not start until the web app is fully launched and Stripe is live. Building mobile against a moving backend creates maintenance debt on two codebases simultaneously.

Platform

React Native (Expo)

  • Single codebase — iOS and Android
  • TypeScript (same as web)
  • Expo Go for device testing without App Store review

  • Google Play Console

Shared with web

  • All workshops, stock, listings data
  • Stripe customer & subscription records
  • API keys for camera integration
  • TypeScript types (shared or duplicated)

🔮 Future Features — Phase 6+

Identified for development after the core platform is stable and live (Phases 1–5). Detailed design required before implementation.

💬

In-App Messaging & Enquiry Tracking

Replace email-only enquiries with real-time in-app chat. Every message is stored and admin-auditable to prevent fraud and out-of-app transactions.

  • Message threads tied to a specific listing for context
  • Auto-moderation: flag bank details, external payment links, phone numbers
  • Typing indicators + read receipts via Supabase Realtime
  • Admin view of all flagged conversations
Tech: messages table · Supabase Realtime · server-side moderation on insert
🤝

Offer & Negotiation System

Buyers submit counter-offers below the listed price. Sellers can Accept, Counter, or Decline. Accepted offers trigger the Stripe payment flow automatically.

  • Offers expire after 48 hours with no response
  • Full offer history visible to both parties
  • Admin can view all offers for compliance
  • Resend email notifications on each status change
Tech: offers table (listing_id, price_pence, status, expires_at) · Resend
📦

Bundle & Quantity Discount Tiers

Sellers configure tiered pricing on any listing. Price per piece drops automatically as quantity increases — calculated at checkout.

  • Example: 1–4 pieces £12 each · 5–9 £10 · 10+ £8
  • Pricing table shown on listing cards and detail page
  • Applied automatically based on buyer's selected quantity
Tech: listing_price_tiers table (listing_id, min_qty, price_pence)
🔍

AI Photo Verification

When photos are uploaded, an AI check verifies the image is plausibly relevant to the declared material and category. Mismatches are flagged for admin review — not blocked outright.

  • Detects obvious mismatches (face photo on an oak board listing)
  • Confidence score stored on listing_images
  • Listings remain live — admin reviews flagged photos
Tech: Claude API (vision) in upload Server Action · verification_status on listing_images
🤖

In-App AI Material Search Chatbot

Natural language search inside the app. Type a requirement and the chatbot queries live listings and surfaces workshops that regularly stock those materials.

  • "I need 20 sheets of 18mm birch ply within 50 miles of Bristol"
  • Claude API with tool use runs structured DB queries
  • Streamed responses with direct links to matching listings
Tech: Claude API (tool use) · streamed UI · /chat route
🎮

Discord Community & Stock Alert Bot

Official Discord server for the Offcut Challenge community with a bot that posts new listings and sends personalised stock alerts to subscribed workshops.

  • #new-listings: auto-post when items go live (filterable by category)
  • #stock-alerts: subscribe to specific materials or dimensions
  • Bot command: !search oak 18mm returns live matching listings
  • Platform release notes pushed automatically
Tech: Discord.js bot · Supabase webhooks / pg_notify · Discord REST API
