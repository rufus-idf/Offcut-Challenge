Core Capabilities

Everything in one program

True DXF Geometry

Reads actual polylines, arcs, and drill holes from DXF. Handles LWPOLYLINE bulge values and standalone ARC entities — curved parts cut as curves, not approximations.

PDF Job Sheets

One click generates a professional PDF — parts list, quantities, board used, machine, and a printed nesting layout. Ready for the workshop floor or client records.

Per-Job Depth Control

Set exact cutting depths per drill diameter and router before generating code. Pass counts calculated automatically from tool step-down. Nothing hardcoded.

Cloud Tool Libraries

Every machine's routers and drills — diameters, tool numbers, feed rates, plunge rates, spindle speeds — stored in Google Sheets and synced on every launch.

Automatic Job Log

Every generated job is logged to CSV — timestamp, machine, board, parts, export path. Full traceability of what was cut, when, and where the file went.

Grain Direction Tracking

Parts can be individually rotated to respect grain. The app tracks orientation per part and the bin-packer respects it when placing parts on the board.
